## Overview
A Vulkan-based 3D renderer built in C++ as part of a Graphics Programming course.  
Features a fully refactored architecture with clean separation of concerns across  
core, rendering, frame, and resource management layers.

## Controls
| Input | Action |
|-------|--------|
| `W A S D` | Move camera forward / left / back / right |
| `Q / E` | Move camera down / up |
| `Right Mouse Button` | Capture mouse and look around |
| `Escape` | Release mouse |
| `Scroll Wheel` | Zoom in / out |
